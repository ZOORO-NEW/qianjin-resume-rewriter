# 求职武器库六件套方法论（v2.0 新增）

> **核心心法**：简历只是武器库的 1/6。真正的求职胜负在「简历 + Cover Letter + 30 秒自我介绍 + 面试题库 + 项目案例 + docx 排版」六件套的协同。
>
> 单一简历的转化率，不如六件套的协同转化率。

---

## 六件套总览

| 套件 | 用途 | 使用频率 |
|------|------|---------|
| 1️⃣ 简历多线版 | 投递与展示 | 每次投递 |
| 2️⃣ Cover Letter | 邮件/私信开场 | 每次投递 |
| 3️⃣ 30 秒自我介绍 | 电话/面试/破冰 | 每次沟通 |
| 4️⃣ 面试题库 | 面试前准备 | 面试前 1 次 |
| 5️⃣ 项目案例 | 深度项目深挖 | 关键面试/销售 |
| 6️⃣ docx 排版落地 | 投递材料美化 | 投递前 |

## 1️⃣ 简历多线定位策略（最关键）

### 核心原则：一份简历 = 一个定位

一份简历只服务一个目标场景。**不要把「定位 A（顾问/销售型）」和「定位 C（通用求职版）」混在一起**——两种姿态、两种数据、两种决策语言，混在一起等于都不打中。

### 三种典型定位

#### 定位 A：销售工具版（顾问/自由职业）

- **目标读者**：客户 CMO/CEO/CTO
- **核心诉求**：约 30 分钟诊断
- **姿态**："我提供判断"（平等的销售者）
- **数据重心**：倍数（20倍、5倍）—— 证明 ROI
- **独特章节**：客户画像、服务方式三步走、30 分钟诊断承诺
- **结尾**：合作方式（不是联系方式）

#### 定位 B：战略决策者版（VP/高管求职）

- **目标读者**：目标岗位 HR/猎头/CXO
- **核心诉求**：面试机会
- **姿态**："我承接战略责任"
- **数据重心**：规模（亿级 GMV / 万级月GMV）—— 证明能担盘子
- **独特章节**：战略判断力、复合领导力
- **结尾**：求职匹配与联系方式

#### 定位 C：通用求职版（总监级）

- **目标读者**：HR 经理/招聘负责人/部门总经理
- **核心诉求**：投递通过率
- **姿态**："我能交付结果"（职业化）
- **数据重心**：倍数 + 规模混合
- **独特章节**：求职意向、自我评价
- **结尾**：联系方式

### 何时启用哪种

```
用户问"改简历"
  ↓
问：你打算用这份简历做什么？
  ├─ 主动联系客户做顾问 → 用定位 A
  ├─ 投战略决策者岗位（VP/高管） → 用定位 B  
  ├─ 投总监级岗位 → 用定位 C
  └─ 都不确定 → 默认生成定位 C（最通用），
                提示用户可生成 A/B 版本
```

## 2️⃣ Cover Letter 写作框架

### 三种 Cover Letter 模板

#### A. 顾问版（销售型）

**核心结构**：
1. 主题行："关于贵司 [业务] 的 AI 增长机会 - [名字]"
2. 我是谁：1 句话定位
3. 为什么找您：基于研究的 3 个杠杆点（具体观察）
4. 实战背书：3 个关键战绩（数字）
5. 合作模式：3 种服务方式表格
6. 结尾：30 分钟诊断邀请

**核心原则**：
- 第一句必提"我研究过贵司 X"（证明不是群发）
- 至少 1 个具体观察（不是"贵司品牌很好"这种废话）
- 不直接报价格（先聊 30 分钟再说）

#### B. VP 求职版（战略型）

**核心结构**：
1. 主题行："[名字]｜应聘 [岗位]｜[核心战绩]"
2. 一句话定位：30 秒电梯自我介绍的浓缩版
3. 为什么适合贵司：3-4 个差异化点
4. 简历 + 作品集附件
5. 期待面试

**核心原则**：
- 350 字以内（CXO 看 30 秒决定）
- 每个数据后跟"与贵司 X 业务的高度契合"
- 用动词+数字+结果，禁用形容词

#### C. 通用求职版（职业型）

**核心结构**：
1. 主题行："应聘 [岗位] - [名字]"
2. 自我介绍：1 段
3. 匹配点：3 个理由
4. 结尾：期待面试机会

### 3 个发送策略

1. **发送时机**：周一上午 10:00-11:30（高管处理邮件黄金时段）
2. **个性化 3 件事**：
   - 第一句提"我研究过贵司 X"
   - 至少 1 个具体观察
   - 不直接报价格
3. **跟进节奏**：
   - Day 0：首次联系
   - Day 5：跟进 1（确认收到）
   - Day 12：跟进 2（提供新洞察，不是单纯催）
   - Day 20：跟进 3（明确收尾）

## 3️⃣ 30 秒自我介绍框架

### 核心结构

```
一句话定位（10 秒）
  ↓
3 个项目 = 3 种能力（15 秒）
  ↓
1 个差异化（5 秒）
```

### 模板

> "您好，我是[名字]。我做了[X]年[领域]，现在专攻一件事——[差异化定位]。
>
> 我过去主导过[项目1]，[数据1]；也把[项目2]从[起点]做到[终点]，[数据2]。
>
> 现在我在[当前业务]，[数据3]。
>
> 简单说——[差异化能力]，这就是 [场景] 最缺的。"

### 4 个长度版本

| 版本 | 长度 | 场景 |
|------|------|------|
| 超短版 | 15 秒 | 电话/破冰 |
| 标准版 | 30 秒 | 邮件/面试开场 |
| 加长版 | 60 秒 | 饭局/深度交流 |
| 完整版 | 90 秒 | 终面/重要决策者 |

### 5 个场景开场白

1. 邮件/LinkedIn 私信
2. 电话开场
3. 当面寒暄/饭局
4. 面试第一题
5. 朋友圈/个人 IP 简介

### 核心数据弹药（备用）

无论多长版本，**至少带 1 个核心数据**：
- 规模型（GMV/营收）
- 倍数型（增长/效率）
- 用户型（粉丝/客户数）
- 时长型（X 年）

## 4️⃣ VP 面试 10 题题库

### 10 个高频题

1. 请做个自我介绍
2. 你为什么想离开现在的公司？
3. 如果我录用你，前 90 天你的行动计划是什么？
4. 你过去最大的失败是什么？学到了什么？
5. 你如何理解 [行业] 未来 3 年的核心增长曲线？
6. 你如何管理比你资深的总监级团队？
7. AI 在你眼里的真实价值是什么？哪些是噱头？
8. 你如何看待 ESG 在 [行业] 的未来？
9. 你的薪资预期和理由？
10. 你有什么要问我们的？

### 答题核心结构（每题）

```
判断先行（10%）
  ↓
数据支撑（60%）
  ↓
决策反思（30%）
```

### 5 个杀手锏题

- **Q4 最大失败**：用真实失败+真实代价+真实复盘，而非"我太追求完美"这种假失败
- **Q5 行业判断**：1 个核心判断 + 3 个支撑变量 + 1 个反直觉观点
- **Q7 AI 真实价值**：3 个真实场景 + 3 个警惕方向 + 1 个落地经验
- **Q9 薪资预期**：业务挑战 > 股权 > 规模 > 现金（VP 优先级）
- **Q10 反向提问**：3 个高管级问题（战略判断 / 组织期待 / 反向尽调）

### 反向提问 3 问（VP 面试胜负手）

1. "未来 18 个月，您认为贵司最关键的 3 个战略决策是什么？"
2. "您期望这个 VP 在加入 12 个月内交付的最重要的 1 件事是什么？"
3. "如果我来，您认为最大的挑战会是什么？您会怎么帮我对抗这个挑战？"

## 5️⃣ 30 分钟项目案例框架

### 时间分配

```
00:00-03:00  Part 1 · 项目背景与战略判断
03:00-10:00  Part 2 · 顶层设计：N 个关键决策
10:00-18:00  Part 3 · 落地执行：N 条增长曲线
18:00-22:00  Part 4 · 关键数据与单位经济模型
22:00-25:00  Part 5 · 复盘与可迁移方法论
25:00-30:00  Part 6 · Q&A / 反向提问
```

### 5 个决策点（最关键）

项目做成不是"做了多少动作"，是"做了几个正确决策"。

每个决策需要：
- 背景（30 秒）
- 选项对比（1 分钟）
- 选择理由（1 分钟）
- 实际落地（30 秒）
- 关键数据（30 秒）

### 单位经济模型（CXO 最关心）

必背 4 个指标：
- CAC 获客成本
- LTV 用户终身价值
- LTV/CAC 比（行业优秀线 5:1，顶级 10:1）
- 回本周期（月）

### Q&A 5 个被追问细节

提前准备：
1. 项目最终是否达到预期？
2. 你的核心贡献是什么？
3. 为什么离开？
4. 如果重做，你会改什么？
5. 这套方法如何迁移到贵司？

## 6️⃣ docx 排版落地手册

### 配色方案

**商务深蓝版（默认，专业稳重）**：
- PRIMARY：#1F3A5F（深蓝主色）
- ACCENT：#C0392B（砖红强调）
- TEXT：#2C2C2C（正文深灰）
- SUBTITLE：#555555（副标题灰）
- LIGHT：#888888（浅灰）

**黑金奢华版**：
- PRIMARY：#1A1A1A（黑）
- ACCENT：#B8860B（金）
- 适合：高端品牌、奢侈品行业

**红黑力量版**：
- PRIMARY：#222222（深黑）
- ACCENT：#E63946（红）
- 适合：互联网、新消费、强气场行业

**灰蓝冷静版**：
- PRIMARY：#34495E（灰蓝）
- ACCENT：#2980B9（亮蓝）
- 适合：金融、咨询、稳健行业

### 排版关键元素

#### 标题区
- 中文姓名 24pt 粗体居中
- 装饰线 + 两行联系方式

#### 章节标题
- **深蓝背景 + 白字 + 留白** —— 视觉锚点
- 13pt 粗体，加 padding

#### 工作经历（每段）
- **时间（深蓝粗）| 项目名（红色粗）** 三段式
- 底部灰色细线分隔（#D9D9D9）
- 副标题（公司名 + 职位）灰字
- "项目挑战" / "核心成果" 标签加粗深蓝

#### 关键数据
- **红色左边框 + 浅粉底**（#FDF2F0）—— 视觉高亮
- 让 HR 一眼看到数字

#### 表格
- 表头深蓝白字
- 行交替灰白（#F0F4F8）
- 数据列红色加粗突出
- 全部加细边框（#B0B0B0）

#### AI Agent / 列表
- 箭头 ▸ + 代码名（英文粗体 Calibri）+ 描述

## 武器库交付清单（v2.0）

### 用户说"改简历"时

1. 问目标场景：投递 / 顾问 / VP 求职？
2. 读取原简历（python-docx 提取）
3. 按定位生成简历（A/B/C 三种之一）
4. 提示是否需要配套武器（Cover Letter / 自我介绍 / 面试题库 / 项目案例 / docx 排版）

### 完整武器库交付

```
✅ 简历（按定位：A/B/C）
✅ Cover Letter（同定位）
✅ 30 秒自我介绍（多长度版本）
✅ 面试题库（如适用 VP）
✅ 项目案例（深挖最核心项目）
✅ docx 排版美化版
```

### 红线

1. **数据真实性**：所有数字必须来自用户原素材，禁止编造
2. **离职原因**：保留外部原因（政策/疫情/资金链），删除自辩性内容
3. **原文优先**：用户原发 docx 一字不改，只美化排版
4. **多线定位**：明确问清定位再写，避免一份简历打所有岗位

### 武器库专属红线（v2.1.0 新增，实测教训）

武器库是简历的**延伸**，最容易在配套材料里"顺手放大"战绩 —— 简历正文守住了，Cover Letter 里写出另一个数字，投出去就是自己打自己。

1. **跨材料口径必须一致**：Cover Letter / 自我介绍 / 项目案例里的每个数字，都要与简历正文完全一致。正文写"约 6.7 倍"，Cover Letter 就不能写"7 倍"或"增长 6.7 倍"。
2. **引用战绩前先回查原文**：实测出现过把"GMV 由 300 万增至 2000 万"记成"1000 万到 2000 万"——**记忆会漂移，写之前必须回看素材原文**。
3. **不替用户免检**：不能写"以上数据均已与您确认"这类自我声明，除非真的逐条核过。错的声明比漏改风险更高。
4. **不夸大头衔**：简历里是"高级运营"，Cover Letter 里就不能变成"电商总监候选人"。头衔一致性同样适用于称呼（"X总"仅用于确有其事的正式场合）。
5. **承认差距不等于自毁**：错配时用「诚实 + 换维度打」（如JD 的"从 0-1 **或** 从 1 到 N"里，"或"字就是入口），**不要编数字去够那条够不着的线**。
6. **推断型话术要标注**：面试答题要点里若使用了素材外的推演（如"从 GMV 与会员的比例看出你的失败"），要提示用户**先自查是否认同自己的结论**，不认同就换切口——不要伪装成用户亲历。
